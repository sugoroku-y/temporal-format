# 書式文字列

`format`/`parse`で整形/解析に使用する書式を指定する文字列です。

- 連続する1文字から9文字までの同じアルファベットを、書式指定子とみなします。
- アルファベット以外の文字はリテラル文字列として扱われます。
- アルファベットをリテラル文字列としたい場合にはシングルクォート(`'`)もしくはダブルクォート(`"`)で囲みます。
- シングルクォートやダブルクォートをリテラル文字列としたい場合には引用符内外にかかわらず`''`や`""`のように2つ重ねます。

| 書式指定子        | プロパティ  | 例      | 説明       |
|-------------------|-------------|---------|------------|
| `yyyy`            | `year`      | `2026` | 4桁の西暦 |
| `yy`              | `year`      | `26` | 下2桁の西暦 |
| `M`               | `monthCode` | `8`, `12` | 桁揃えなしの月 |
| `MM`              | `monthCode` | `08`, `12` | 2桁の月 |
| `MMM`             | `monthCode` | `Aug`, `Dec` | 月の英語略称 |
| `MMMM`            | `monthCode` | `August`, `December` | 月の英語表記 |
| `d`               | `day`       | `9`, `28` | 桁揃えなしの日 |
| `dd`              | `day`       | `09`, `28` | 2桁の日 |
| `H`               | `hour`      | `02`, `21` | 24時間表記の時間 |
| `HH`              | `hour`      | `02`, `21` | 2桁の24時間表記の時間 |
| `h`               | `hour`      | `9`, `12` | 12時間表記の時間 |
| `hh`              | `hour`      | `09`, `12` | 2桁の12時間表記の時間 |
| `a`               | `hour`      | `AM`, `PM` | 午前/午後 |
| `m`               | `minute`    | `3`, `56` | 桁揃えなしの分 |
| `mm`              | `minute`    | `03`, `56` | 2桁の分 |
| `s`               | `second`    | `5`, `48` | 桁揃えなしの秒 |
| `ss`              | `second`    | `05`, `48` | 2桁の秒 |
| `S`,`SS`, ...     | `millisecond`,| `1`, `12`, ...  | 1桁〜9桁の |
| ..., `SSSSS`, ... | `microsecond`, | ..., `12345`, ... | 小数点以下 |
| ...`SSSSSSSSS`    | `nanosecond`         | ...`123456789` | の秒 |
| `E`, `EE`, `EEE`| `dayOfWeek` | `Mon`, `Thu` | 曜日の英語略称 |
| `EEEE` | `dayOfWeek` | `Monday`, `Thursday` | 曜日の英語表記 |

将来の拡張のため、同じアルファベットが1文字から9文字連続しているものは書式指定子として予約されており、
上記の表にないものが使用されるとエラーになります。

アルファベットをリテラル文字列として使用したい場合は、シングルクォートで囲む必要があります。
たとえば、`'T'` は文字列 "T" を表し、予約された書式指定子ではありません。

シングルクォートを文字列として使用したい場合は、2つ連続してシングルクォートを使用する必要があります。
たとえば、`''` は "'" 1文字に変換されます。

クォートされた文字列の中で、シングルクオートを使いたい場合にも、2つ連続してシングルクォートを使用する必要があります。
たとえば、`'o''clock'` は文字列 "o'clock" に変換されます。

閉じられていないシングルクォートがあるとエラーになります。

有効な書式指定子が1つもないとエラーになります。

(parse限定) 日付や時刻のプロパティの書式指定子が1つ以上指定されていないとエラーになります。

(parse限定) `a`(午前/午後)と`h`/`hh`(12時間制表記の時間)は組み合わせて指定しないとエラーになります。
