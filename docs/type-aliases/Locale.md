# 型エイリアス: Locale

> **Locale** = keyof *typeof* `LOCALES`

整形/解析で使用するロケール

以下のものが使用できます。

- `en-US` 英語(デフォルト)

  以下の文字列が使用されます。

  | 書式指定子       | 結果                  |
  |------------------|-----------------------|
  | `MMM`            | `Jan`〜`Dec`          |
  | `MMMM`           | `January`〜`December` |
  | `E`, `EE`, `EEE` | `Mon`〜`Sun`          |
  | `EEEE`           | `Monday`〜`Sunday`    |
  | `a`              | `AM`, `PM`            |

- `ja-JP` 日本語

  以下の文字列が使用されます。

  | 書式指定子       | 結果                |
  |------------------|---------------------|
  | `MMM`, `MMMM`    | `1月`〜`12月`       |
  | `E`, `EE`, `EEE` | `月`〜`日`          |
  | `EEEE`           | `月曜日`〜`日曜日`  |
  | `a`              | `午前`, `午後`      |

上記以外を指定するとエラーになります。
